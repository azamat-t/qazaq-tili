# qazaq-tili

Қазақ тіліндегі сөздерді септіктер бойынша түрлендіру және сөздің септігін жалғауы бойынша анықтау. Сыртқы тәуелділіктері жоқ.

[Ағылшын тіліндегі нұсқаулық](./en.md)

[Орыс тіліндегі нұсқаулық](../README.md)

```js
jalgau('Алмас', 'b') // 'Алмасқа'
jalgau('кітап', 'sh', true) // 'кітаптардан'
getJalgau('Серіктің') // { septik: 'Ілік', latin: 'Ilik', key: 'i', code: 1 }
```

## Орнату

```bash
npm install qazaq-tili
```

## Қосу

```js
const { jalgau, getJalgau } = require('qazaq-tili')
// немесе
import { jalgau, getJalgau } from 'qazaq-tili'
```

## Септіктер

Септікті санмен немесе жол кілтімен көрсетуге болады:

| Код |  Кілт  | Атауы    | Latin    | Орыс тіліндегі баламасы   | Сұрақтары              | Жалғаулары                       |
| :-: | :----: | -------- | -------- | ------------------------- | ---------------------- | -------------------------------- |
| `0` | `'a'`  | Атау     | Atau     | Именительный              | кім? не?               | —                                |
| `1` | `'i'`  | Ілік     | Ilik     | Родительный               | кімнің? ненің?         | -ның/-нің, -дың/-дің, -тың/-тің  |
| `2` | `'b'`  | Барыс    | Barys    | Дательно-направительный   | кімге? неге? қайда?    | -ға/-ге, -қа/-ке, -на/-не, -а/-е |
| `3` | `'t'`  | Табыс    | Tabys    | Винительный               | кімді? нені?           | -ны/-ні, -ды/-ді, -ты/-ті, -н    |
| `4` | `'j'`  | Жатыс    | Jatys    | Местный                   | кімде? неде? қайда?    | -да/-де, -та/-те, -нда/-нде      |
| `5` | `'sh'` | Шығыс    | Shygys   | Исходный                  | кімнен? неден? қайдан? | -дан/-ден, -тан/-тен, -нан/-нен  |
| `6` | `'k'`  | Көмектес | Komektes | Творительный / совместный | кіммен? немен?         | -мен, -бен, -пен                 |

## `jalgau(word, septik = 0, koptik = false)`

Сөзді қажетті септікке қояды. Жалғаудың жуан немесе жіңішке түрі автоматты түрде таңдалады.

| Параметр | Түрі               | Сипаттамасы                                                           |
| -------- | ------------------ | --------------------------------------------------------------------- |
| `word`   | `string`           | Атау тұлғадағы сөз                                                    |
| `septik` | `number \| string` | Септік: `0–6` немесе `'a'`, `'i'`, `'b'`, `'t'`, `'j'`, `'sh'`, `'k'` |
| `koptik` | `boolean`          | `true` — көптік жалғауын қосу                                         |

```js
jalgau('қала', 'j') // 'қалада'
jalgau('мектеп', 'b') // 'мектепке'
jalgau('Әлия', 'i') // 'Әлияның'
jalgau('Айгүл', 'k') // 'Айгүлмен'
jalgau('Мұрат', 2) // 'Мұратқа'
```

Көптік жалғау:

```js
jalgau('кітап', 'a', true) // 'кітаптар'
jalgau('кітап', 'i', true) // 'кітаптардың'
jalgau('адам', 'b', true) // 'адамдарға'
jalgau('мектеп', 'j', true) // 'мектептерде'
```

## `getJalgau(sourceWord, targetWord?)`

Сөздің септігін жалғауы бойынша анықтайды.

```js
getJalgau('Серіктің') // { septik: 'Ілік',  latin: 'Ilik',   key: 'i',  code: 1 }
getJalgau('қаладан') // { septik: 'Шығыс', latin: 'Shygys', key: 'sh', code: 5 }
getJalgau('Серік') // { septik: 'Атау',  latin: 'Atau',   key: 'a',  code: 0 }
```

Екінші сөзді берсеңіз, функция оны дәл сол септікте қайтарады:

```js
getJalgau('Серіктің', 'Алмаз') // 'Алмаздың'
getJalgau('мектепте', 'қала') // 'қалада'
getJalgau('Айгүлге', 'Мұрат') // 'Мұратқа'
```

## Қолдану мысалдары

```js
const { jalgau } = require('qazaq-tili')

// Хабарлама мәтіні
const msg = `${jalgau('Алмас', 'sh')} ${jalgau('Серік', 'b')} 5000 ₸ аударылды`
// 'Алмастан Серікке 5000 ₸ аударылды'

// Сөздің барлық септік түрлері
const forms = ['a', 'i', 'b', 't', 'j', 'sh', 'k'].map((k) => jalgau('қала', k))
// ['қала', 'қаланың', 'қалаға', 'қаланы', 'қалада', 'қаладан', 'қаламен']
```

## Қателер

Егер `word` немесе `sourceWord` жол (string) болмаса, сондай-ақ белгісіз септік берілсе (мысалы, `7`, `'x'` немесе `1` санының орнына `'1'` жолы), функциялар `Error` қатесін лақтырады.

## Білген жөн

- `jalgau` функциясына сөзді атау тұлғасында, артық бос орынсыз беріңіз (`trim()` қолданыңыз).
- Жалғау әрқашан кіші әріппен қосылады: `jalgau('АЛМАС', 'i')` → `'АЛМАСтың'`.
- `getJalgau` септікті тек сөздің соңғы әріптері бойынша анықтайды. Сондықтан соңы жалғауға ұқсайтын атау тұлғадағы сөз қате анықталуы мүмкін: мысалы, `getJalgau('Қазақстан')` → Шығыс.
